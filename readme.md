# 大明王朝RPG - 复古像素RPG

以朱元璋生平为主线的2D复古像素单机RPG。从钟离少年起步，经历放牛、皇觉寺出家、投军、大战陈友谅、消灭张士诚、北伐灭元，最终建立大明王朝通关。

技术栈：Python + Pygame | 风格参考：FC吞食天地2 | 格子规格：24×24像素

---

## 一、环境要求

- Python 3.8+
- Pygame 2.0+

## 二、安装依赖

```bash
pip install pygame
```

## 三、启动游戏

```bash
cd ming_rpg_daming
python main.py
```

## 四、操作说明

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 角色移动 |
| 空格 | 砍伐树木 / 推进对话 / 战斗确认 |
| G | 开启/关闭挂机模式（每秒自动获得经验，角色原地不动） |
| E | 打开/关闭装备面板 |
| F1 | 开启/关闭内置地图编辑器 |
| 1-9 | 编辑器模式下切换地块类型 |
| S | 编辑器模式下保存地图到JSON |
| 战斗中 1 | 攻击 |
| 战斗中 2 | 逃跑（BOSS战不可逃跑） |

## 五、可调参数（直接修改main.py顶部数值）

在 `main.py` 顶部有明确注释标记的参数：

```python
MOVE_SPEED = 3            # 【移动速度】像素/帧，范围1-6
EXP_MULTIPLIER = 1.0      # 【经验倍率】全局经验获取倍率
AFK_EXP_PER_SEC = 8       # 【挂机经验】挂机模式每秒经验
DROP_RATE_TREE = 0.35     # 【砍树掉落率】0~1
DROP_RATE_MONSTER = 0.65  # 【怪物掉落率】0~1
TILE_SIZE = 24            # 像素格子大小
```

修改后保存重新运行即可生效，无需改动其他代码。

## 六、游戏流程

```
钟离北(Lv1) → 钟离南(Lv1) → 皇觉寺(Lv3) → 苏州(Lv6)
→ 太平府(Lv10) → 应天府(Lv15) → 徽州(Lv18)
→ 浙东(Lv22, 陈友谅/张士诚BOSS) → 元大都(Lv28, 元顺帝最终BOSS)
```

- 等级不足时进入高级地图会被拦截并提示
- 砍树和击杀怪物可获得经验和装备
- 挂机模式可安全升级，但经验远低于击杀怪物
- 装备品质：白 < 绿 < 蓝 < 紫 < 金 < 红
- 顶级装备：倚天剑（红）、屠龙刀（金）、龙袍（红）

## 七、项目结构

```
ming_rpg_daming/
├─ main.py              # 游戏主入口（全部业务逻辑）
├─ settings.json        # VSCode编辑器UTF-8编码配置
├─ gen_data.py          # 数据生成脚本（可重新生成JSON）
├─ test_game.py         # 自动化逻辑测试
├─ smoke_test.py        # 运行时烟雾测试
├─ assets/              # 像素素材目录（需自行放入）
│   ├─ tiles/           # 地图地块素材
│   ├─ sprites/         # 角色精灵素材
│   └─ items/           # 装备道具素材
├─ map/                 # 9张地图JSON（UTF-8编码）
├─ data/                # 装备/剧情/等级解锁JSON（UTF-8编码）
└─ readme.md            # 本文件
```

## 八、中文编码说明

- 所有游戏数据JSON文件使用 **UTF-8编码**
- `settings.json` 配置VSCode以UTF-8打开项目文件
- 代码中通过 `load_json()` 函数统一读取UTF-8文件
- 字体优先使用系统中文字体（微软雅黑/黑体/宋体），未找到时回退默认字体

## 九、地图编辑器

按 `F1` 进入编辑模式：
- 鼠标左键：放置当前选中地块
- 鼠标右键：擦除为草地
- 数字键1-9：切换地块类型
- S键：保存当前地图为 `map/<地图名>_edited.json`
- F1：退出编辑模式
